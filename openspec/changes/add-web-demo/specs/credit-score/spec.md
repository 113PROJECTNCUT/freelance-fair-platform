# Spec Delta

## Purpose

讓發案方用客觀的交易紀錄判斷接案者的可靠度，而不是只看報價或自我介紹。

## ADDED Requirements

### Requirement: 信用分數計算
系統 SHALL 以準時交付率 40%、一次驗收通過率 30%、雙方互評 20%、爭議紀錄 10% 計算 0–100 分；爭議率達 20% 以上時爭議項為 0。

#### Scenario: 全部滿分
- **WHEN** 接案者完成 10 件、全部準時、全部一次通過、平均評價 5 分、無爭議
- **THEN** 信用分數為 100

### Requirement: 資料不足標示
完成案件少於 3 件時，系統 MUST 不顯示分數，改標示為「新進接案者」。

#### Scenario: 新進接案者
- **WHEN** 接案者僅完成 2 件
- **THEN** 顯示「新進接案者」，不顯示分數
