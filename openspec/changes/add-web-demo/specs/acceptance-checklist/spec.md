# Spec Delta

## Purpose

把發案方的需求描述轉成雙方都看得懂、可逐項勾選的驗收標準，作為交付與驗收的共同依據。

## ADDED Requirements

### Requirement: 需求轉驗收清單
系統 SHALL 將需求描述逐句轉為交付項目，依案件類型補充常見驗收項目，並加入交期、免費修改次數與預設驗收期限。

#### Scenario: 網站案件
- **WHEN** 需求描述包含「網站」與「表單」，工期 30 天、免費修改 2 次
- **THEN** 清單包含 RWD 項目、表單通知項目、「於簽約後 30 日內完成交付」與「包含 2 次免費修改」

### Requirement: 發案方確認
發案方 SHALL 可在確認前新增或刪除項目；確認後清單即鎖定，不可再修改。

#### Scenario: 確認後鎖定
- **WHEN** 發案方按下「確認清單並刊登」
- **THEN** 刪除與新增功能隱藏，並提示接案者投標前會看到此清單
