# Spec Delta

## Purpose

讓款項依里程碑分期託管，驗收通過才撥款，並清楚呈現平台手續費與接案者實收金額。

## ADDED Requirements

### Requirement: 分期金額與手續費
系統 SHALL 依各期比例計算託管金額，撥款時扣除 6% 平台手續費並顯示接案者實收；各期比例合計不為 100% 時 MUST 顯示警告。

#### Scenario: 6 萬元三期
- **WHEN** 總金額 60,000 元，比例 30%／40%／30%
- **THEN** 第 2 期託管 24,000 元、手續費 1,440 元、接案者實收 22,560 元

### Requirement: 驗收狀態流轉
每一期 SHALL 依「待交付 → 待驗收 → 已撥款」流轉；待驗收時發案方可退回修正或申請仲裁，仲裁結果為撥款或退回修正。

#### Scenario: 驗收未通過
- **WHEN** 發案方在待驗收狀態按下「退回」
- **THEN** 該期狀態變為「退回修正」，接案者可重新交付
